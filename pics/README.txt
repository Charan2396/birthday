Optional photos for the private page.

Add them as 1.jpg, 2.jpg, 3.jpg ...

Then put this line somewhere in private-draft/her-content.html and re-seal:

    <div class="p-gallery" data-count="12" data-dir="pics"></div>

Set data-count to how many you added. Missing files hide themselves,
so it is fine if the number is a little off.

HEADS UP: files in this folder are PUBLIC even though the page is locked.
Encryption hides the words, not the image files - anyone who guesses
pics/1.jpg can open it. Only put photos here you would not mind someone
stumbling onto.
